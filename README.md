## 📌 Descripción General

Este repositorio contiene la implementación y entrega de **🎨 Web UI Component Architecture & Responsive Design (Seminario 1)**, desarrollado en el curso de **Seminario de Sistemas 1** en la Universidad de San Carlos de Guatemala.
